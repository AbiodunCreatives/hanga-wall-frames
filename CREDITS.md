# Hanga collection credits

These artworks were added to the Browse & Customise gallery from museum open-access programmes.
Each item was confirmed public domain / CC0 via the museum API at fetch time
(`isPublicDomain` on The Met, `is_public_domain` on the Art Institute of Chicago).

Web images in `images/collection/` are resized to about 1200px on the long side for the site.
Print-quality originals are **not** stored in this repo. When an order comes in, download the
high-resolution file from `print_image_url` in `data/collection-credits.json` (also listed below).
